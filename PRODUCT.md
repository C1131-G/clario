# Clario Product Truth

Clario is a web application for non-technical SAP Business One managers. It provides conversational business intelligence for plain-language business questions.

This phase is a browser-memory-only frontend. AI, authentication, persistence, databases, SAP connectivity, and API work are deferred to the backend phase. The interface targets WCAG 2.2 AA and preserves Clario's existing typography, theme, and shadcn component system.
